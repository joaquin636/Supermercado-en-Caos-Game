# Implementación de la candidata

La arquitectura vigente se describe en ARQUITECTURA.md. El catálogo contiene seis niveles y la lógica de comandos utiliza State. La integración Observer del panel está implementada desde GamePanel.java y el envío de estadísticas utiliza HTTP asíncrono.

Compila con los scripts de la raíz y un JDK 17 o superior. sources.txt enumera la aplicación y tests.txt añade la suite. PruebasJuego es el punto de entrada de la verificación automática.

Consulta VALIDACION_FINAL.md para el entorno, el commit, las pruebas ejecutadas y sus límites. GUIA_EXPOSICION.md organiza la demostración y las decisiones que cada integrante debe comprender.
